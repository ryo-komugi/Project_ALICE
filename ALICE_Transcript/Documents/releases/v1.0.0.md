# ALICE_Transcript v1.0.0

Release Date: 2026-07-17

---

## Overview

This is the first stable release of **ALICE_Transcript**.

ALICE_Transcript is an offline speech transcription engine for Project ALICE, designed to continuously process meeting recordings on Ubuntu Server.

---

## Highlights

- First stable release
- Offline speech transcription
- Speaker diarization
- Word-level speaker alignment
- Automatic processing pipeline
- systemd service support

---

## Added

### Speech Processing

- Faster-Whisper transcription
- Pyannote speaker diarization
- Word-level speaker alignment
- Automatic WAV conversion
- Text normalization

### Processing

- Queue-based processing
- Automatic folder monitoring
- Job-based processing pipeline

### File Support

- MP3 support
- M4A support
- WAV support

### Output

- TXT export
- JSON export
- Meeting WAV archive

### Logging

- Runtime logging
- Automatic log archive

### Deployment

- Ubuntu Server support
- systemd service
- Automatic startup

---

## Architecture

The application has been refactored into a modular architecture consisting of:

- WatchFolder
- SyncManager
- Pipeline
- WhisperEngine
- PyannoteEngine
- AlignmentEngine
- TextNormalizer
- Exporter
